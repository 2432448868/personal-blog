## 边界与约束

- **做什么**：完成可在本机启动、建库、开发登录、发文、评论、留言、审核、主题/语言切换和构建验证的完整博客。
- **不做什么**：不推送 Git、不购买域名、不申请 GitHub App/Resend 密钥、不直接修改任何生产数据。
- **技术约束**：Astro + Tailwind CSS + Hono + Cloudflare Workers + D1 + R2；TypeScript；静态优先，动态内容由边缘渲染/API 提供。
- **本地约束**：提供 `AUTH_DEV_MODE`，无第三方密钥也能走完整后台流程；生产环境关闭。
- **数据约束**：D1 使用 SQLite 语法，表包含创建、更新、逻辑删除、操作者与版本公共字段；所有写 SQL 仅落在迁移/种子脚本，由用户决定是否在云端执行。

## 业务规则

### 正常流程
1. 访客浏览首页、文章、分类、标签、归档、留言和关于页。
2. 用户通过 GitHub OAuth 或本地开发登录建立会话。
3. 普通用户发表评论/留言；管理员维护文章和审核互动内容。
4. 管理员发布文章后，列表、搜索、归档和详情立即可见。
5. 评论成功后按需发送 Resend 邮件；失败不影响主流程。

### 异常流程

| 异常场景 | 处理方式 |
|----------|----------|
| 未登录写评论/留言 | 401，前端跳登录 |
| 非管理员进入管理 API | 403 |
| CSRF Token 缺失/不匹配 | 403 |
| OAuth state 过期或校验失败 | 401 并清理临时状态 |
| D1/R2 未绑定 | 服务启动诊断明确报错，不静默伪装成功 |
| 邮件发送失败 | 记录日志，业务成功返回 |
| 封面上传超限或 MIME 非法 | 413/415，不写入 R2 |
| 删除文章/评论 | 逻辑删除，保留审计字段 |

## 验收标准

1. `npm install`、D1 迁移/种子、`npm run build` 全部成功，TypeScript 无错误。
2. 本地启动后首页、文章列表/详情、归档、标签、分类、留言板、关于页均可访问。
3. 开发登录后可进入后台，完成新建草稿、编辑、发布、R2 上传和删除流程。
4. 普通用户评论/留言成功落库；未登录被拒绝；管理员可审核/隐藏。
5. 深浅色、繁简、全屏阅读、打印、搜索可见可用，刷新后偏好保留。
6. Sitemap、Robots、OG、Schema.org 与语义化结构存在。
7. API 冒烟测试覆盖健康检查、文章、评论、留言、登录和权限拒绝。

| 娱乐/工具箱内容数据源未给 | 提供可维护的结构化导航与占位内容，不伪装真实文章数据 | 已设默认 |
| 是否创建 GitHub 仓库/推送 | 不处理 | 已确认 |
