## 1. 需求覆盖度

**检查依据**：需求文档核心页面、用户系统、文章系统、其他功能、非功能要求；方案第 3、4 章。
**发现**：核心链路覆盖完整；娱乐/工具箱内容仅保留导航落点，不能算完整内容产品；邮件为可选降级。
**建议**：本地验收以核心博客、后台、互动、主题/语言/搜索为范围；娱乐/工具箱后续接独立数据源，不伪造“已完成”。

| 需求点 | 覆盖 | 意见 |
|--------|------|------|
| 首页与文章系统 | ✅ | 包含列表、详情、分类、标签、归档 |
| 用户与后台 | ✅ | OAuth PKCE + 开发登录 + CRUD |
| 评论/留言 | ✅ | 含回复和审核 |
| 主题/繁简/全屏/打印 | ✅ | 作为 Islands，需实测浏览器行为 |

| Resend | ⚠️ | 可选集成，无密钥时只验证降级 |
| 娱乐/工具箱 | ⚠️ | 仅导航落点，需求未给出具体内容模型 |
| SEO/性能/安全 | ✅ | 有明确设计，需构建与冒烟验证 |

## 2. 架构一致性

**检查依据**：项目为 Greenfield，无现有框架约束；方案分层、目录和职责已定义。
**发现**：采用单仓单 Worker，和“Astro + Workers + Hono”表述一致，但需明确这是边缘一体化 Worker，不是两个独立部署单元。
**建议**：文档和代码均保持“页面层 → Hono → 服务层 → D1/R2”的边界，禁止组件直接读库。

## 3. 数据层设计

**检查依据**：方案第 4.1 章、SQLite/D1 约束、公共字段要求。
**发现**：关系完整，索引覆盖分页与关联查询；但“公共字段”按 MySQL 模板改为 SQLite 命名，属于适配不是遗漏。
**建议**：
1. 逻辑删除必须进入所有列表查询条件，避免误显示。
2. 关联查询必须 `IN` 批量装配，禁止文章列表逐条查标签。
3. 软删除文章时保留评论审计，列表默认不返回。

## 4. 边界与异常

**检查依据**：方案第 3.3、4.2、5 章。
**发现**：鉴权、CSRF、OAuth state、上传校验、邮件降级均有处理；缺少明确的分页越界和空列表前端状态说明。
**建议**：
1. 分页参数越界自动收敛，不返回 500。
2. 空首页、空评论、无标签分别显示可行动空状态。
3. D1/R2 未绑定在健康检查中明确暴露诊断。

## 5. 过度设计检查

**检查依据**：最小解原则。
**发现**：没有引入 ORM、搜索服务、队列或独立微服务；客户端搜索符合博客规模。但 OAuth + 开发登录双通道需要严格环境门禁，否则是安全风险。
**建议**：开发登录必须同时满足 `ENVIRONMENT=development` 与 `AUTH_DEV_MODE=true`，生产部署默认关闭。

## 6. 可回滚性

**检查依据**：方案第 7 章。
**发现**：数据迁移有回滚目录规划，代码不自动部署；但具体 SQL 尚未生成。
**建议**：实现时每个迁移配套回滚 SQL，且云端执行命令只文档化、不自动运行。

## 7. 风险与门禁

| 级别 | 问题 | 证据 | 建议 | 状态 |
|------|------|------|------|------|
| P1 | 本地无 OAuth 密钥无法验收后台 | 方案 3.2、5 | 开发登录必须真实跑通后再测权限拒绝 | 已关闭 |
| P1 | Worker 对 Markdown 消毒库兼容性未知 | 方案 5 | 构建阶段实际 bundle；不兼容立即客户端化 | 已关闭 |
| P1 | 静态/动态路由边界未用代码验证 | 方案 3.1、4.3 | 构建 + 启动后逐路由冒烟 | 已关闭 |
| P2 | 娱乐/工具箱没有真实数据模型 | 需求 2.2、方案 4.3 | 先保留占位，不宣称完整业务 | 接受 |
| P2 | 客户端全量搜索索引随文章增长变大 | 方案 2.3 | 本文规模可接受，超过 2000 篇切换服务端搜索 | 接受 |
| P2 | 繁简转换可能误伤代码块 | 方案 3.3 | DOM 遍历跳过 code/pre/input/script/style | 待浏览器人工复核 |
| P2 | R2 本地模拟与生产行为存在差异 | 方案 7 | 上传只测本地；生产配置由用户执行 | 接受 |
| P2 | Sitemap 动态内容更新时机未定义 | 方案 4.5 | 改为动态 `sitemap.xml.ts`，实时包含已发布文章 | 已关闭 |

## 8. 结论

**有条件通过**：无 P0；P1 均为实现后必须实测的兼容性/验收项。实现阶段完成 P1 验证并更新 05/06 后，可进入本地交付。
